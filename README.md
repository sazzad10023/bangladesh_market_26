# বাজার দর (BazarDor)

## Description
**BazarDor** is a Bengali-language web application that helps users explore daily prices of essential commodities in Bangladesh. Users can compare product prices, browse categories, view market-wise price ranges, and track price changes.

### Features

- **Daily Market Prices:** Explore current prices of essential commodities such as rice, lentils, oil, vegetables, fish, and meat.
- **Category-Based Browsing:** Browse products by category and sort them by price from low to high or high to low.
- **Product Details:** View today's price, previous price trends, and minimum, maximum, and average prices.
- **Market-Wise Price Comparison:** Compare price ranges across different markets to make informed purchasing decisions.
- **Authentication & Profile Management:** Sign up and sign in using email and password or social authentication, and update profile information.

#### Technologies Used

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Authentication:** Better Auth
- **Database:** MongoDB
- **Notifications:** React Hot Toast
- **Image Optimization:** Next.js Image
